# Integrated Water Vapor Transport (IVT) and Relative Humidity GFS Meteograms

---

This repository runs calculations and plots for the CW3E IVT and Relative Humidity GFS Meteograms for GFS and ECMWF. 

Current capabilities includes point-based 3- or 7-day deterministic forecasts for GFS or ECMWF every degree from 20-60°N and 111-127°W and from 51-69°N and 130-174°W.
